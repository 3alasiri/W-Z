# بقالتي الذكية

نظام لإدارة البقالات: المنتجات، المخزون بالباركود والدفعات وتواريخ الصلاحية، نقطة البيع، والتنبيهات.

## التشغيل
```bash
cd app
cp .env.example .env.local   # بيانات مشروع Supabase
npm install
npm run dev                  # http://localhost:3000
```

## الموجود في المرحلة 1
- تسجيل الدخول وإنشاء متجر (عدة متاجر ومستخدمين مع صلاحيات: مالك، مدير، كاشير، أمين مخزون).
- المنتجات: تعريف بالباركود، الفئات، الموردون، التكلفة والسعر.
- استلام البضاعة بالباركود (قارئ USB أو الكاميرا) مع الكمية وتاريخ الصلاحية والموقع، كل استلام دفعة مستقلة، وتحديث التكلفة بالمتوسط المرجح.
- نقطة البيع: خصم ذري بالأقرب انتهاءً أولًا (FEFO)، يمنع بيع المنتهي والبيع فوق المتوفر، ضريبة 15٪ شاملة، إيصال قابل للطباعة.
- التنبيهات: نفاد، انخفاض تحت نقطة إعادة الطلب المحسوبة، قرب الانتهاء، منتهي مع تسجيله تالفًا.
- لوحة القيادة وسجل المبيعات.

## قاعدة البيانات
الترحيلات في `supabase/migrations`. كل الجداول محمية بـ RLS حسب المتجر، والعمليات الحساسة (البيع، الاستلام، التسوية) تتم عبر دوال تتحقق من الصلاحية.

## الموجود في المرحلة 2
- **المحاسبة:** دليل حسابات افتراضي، وقيد مزدوج تلقائي لكل بيع واستلام وتالف وتسوية وسداد ومصروف، وقائمة الدخل، وإقرار ضريبة القيمة المضافة، وميزان المراجعة، وسجل القيود.
- **العملاء الآجلون:** البيع الآجل من نقطة البيع مع حد ائتمان، والتحصيل، والأرصدة.
- **الموردون:** الأرصدة المستحقة، والسداد نقدًا أو بنكيًا، ورقم الجوال لإرسال الأوامر عبر واتساب.
- **أوامر الشراء:** يجهّزها النظام كل ساعة (pg_cron) لكل مورد عند نزول الكمية تحت نقطة إعادة الطلب، وتُعتمد تلقائيًا تحت حد يحدده المالك، ثم تُرسل وتُستلم كليًا أو جزئيًا مع تاريخ الصلاحية.

التكاليف في النظام قبل الضريبة، وأسعار البيع شاملة الضريبة.
